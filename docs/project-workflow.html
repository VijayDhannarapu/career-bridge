Career-Bridge

A full-stack job portal that connects job seekers and recruiters through role-based authentication,\n profile creation, job listings, application management, and cloud-based storage.

Users

Candidate Flow

  • Sign up with Clerk
  • Complete profile
  • Upload resume PDF
  • Browse and filter jobs
  • Apply and monitor status
Recruiters

Employer Flow

  • Create recruiter account
  • Add company info and logo
  • Post jobs
  • Review applicants
  • Update application decisions
Core Platform

System Layer

  • Next.js front-end
  • Prisma + PostgreSQL
  • Clerk auth & webhooks
  • Cloudinary file storage
  • Role-based routing

Candidate Workflow

1. Authentication

  1. User signs up or signs in through Clerk.
  2. Role is determined as USER or RECRUITER.
  3. App redirects to the correct dashboard.

2. Profile Completion

  1. Candidate fills college, branch, skills, phone, and passout year.
  2. Resume PDF is uploaded and stored in Cloudinary.
  3. The profile is saved in Prisma database.

3. Job Discovery

  1. Candidate lands on the home/job listing page.
  2. Jobs are filtered by query or location/category.
  3. Candidate clicks job details page for more information.

4. Application Process

  1. User applies to a job posting.
  2. Application is saved with status = PENDING.
  3. Candidate can view or withdraw pending applications.

Recruiter Workflow

1. Recruiter Onboarding

  1. Recruiter signs up and sets company name.
  2. Company logo is uploaded via Cloudinary.
  3. Recruiter profile is created in database.

2. Job Posting

  1. Recruiter adds a job title, description, category, and location.
  2. CTC, visibility, and role details are stored.
  3. Job is published to job listings.

3. Candidate Review

  1. All applications tied to that recruiter are queried.
  2. Recruiter filters by category or location.
  3. Candidate details, resume, and application information are reviewed.

4. Decision Making

  1. Recruiter updates application status: PENDING, ACCEPTED, or REJECTED.
  2. Application dashboard revalidates and refreshes.
  3. Candidate sees updated decision through the portal.
